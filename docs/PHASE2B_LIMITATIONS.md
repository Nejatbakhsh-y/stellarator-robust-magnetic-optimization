# Phase 2B limitations

Scientific status remains PARTIAL even if the versioned numerical checks pass.
This is a synthetic device-independent vacuum-filament benchmark, not Thea Energy
geometry or confinement/equilibrium/engineering validation. No affiliation or
proprietary design reconstruction is implied.

The corrected frame is a deterministic convention on the benchmark's declared
normal charts, not a globally smooth tangent frame or a bitwise guarantee on
arbitrary hardware/software. The n_z=0 chart boundary is explicit. A new polygon
phase is an intentional discretization change, not an empirical fit to history.
The default legacy-v1 route remains available and retains its known cross-OS
limitations. Original scientific results and fingerprints are immutable.

The finite peak method reports finite observations. Fixed-budget completion is
not optimizer convergence, and neither local Hessian estimates nor agreement
with Nelder–Mead establishes a global continuum supremum. The field tie band is
a declared computational resolution, not an error bound on the true global
maximum. NM coordinate failures remain retained; the new finite coordinates
are not silently excused from strict comparisons.

Only two training seeds, two counts and 64 IID holdout draws were used. Every
new tested fit worsens the synthetic holdout RMS. Shared holdout/bootstrap
intervals are conditional and dependent across trials. Current-budget matching,
correlated/distribution-shift sensitivity, paired discretization refinement,
formal arithmetic certification and external-code comparisons remain unfinished.
The numerical convex dual audit is not an interval proof. The larger research
preset has not run.

Only actually completed hosted Windows/Linux jobs can establish cross-platform
agreement for the tested package cohorts. One-factor library sensitivity is not
a guarantee for all future versions or BLAS/libm builds. Any outstanding mismatch
must remain visible; thresholds must not be loosened merely to obtain green CI.
